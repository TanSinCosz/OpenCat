# 评测数据与服务

负责读取评测产物、准备数据集、计算展示指标和管理案例工作区。服务入口为 `service.ts`；HTTP 与页面在 `../interfaces/evaluation/`，核心模块不依赖它们。

## 阅读路线

`createEvaluationService(options)` 组装数据集、工作区和运行记录服务。路径与配置快照由入口显式传入；导入本目录不会监听端口、加载数据集或运行 Git / Python。

| 文件 | 职责 | 修改场景 |
| --- | --- | --- |
| `service.ts` | 组装应用所需服务，提供看板调用接口 | 调整依赖或添加服务能力 |
| `runs.ts` | 运行发现、案例详情、数据集展示条目、历史指标回退 | 修改看板显示哪些运行、如何合并产物 |
| `dataset.ts` | 数据集路径选择、查找案例、按配置调用加载器 | 修改 JSON / JSONL 数据来源或准备流程 |
| `metrics.ts` | 事件聚合、摘要补齐、缓存命中率和总计 | 修改指标定义；这里没有文件与网络操作 |
| `conversation.ts` | 读取案例事件与 transcript，转换展示消息 | 修改会话回顾、事件限制和缺失记录的回退 |
| `workspace.ts` | 调用 SWE 工作区服务、导出与保存补丁 | 修改仓库准备和补丁产物路径 |
| `paths.ts` | 在配置允许的评测根目录中选择目录 | 修改数据集选择边界 |
| `records.ts` | 解析旧 JSON / JSONL 产物和不确定字段 | 修改数据格式兼容、坏行诊断 |
| `types.ts` | 运行、案例、指标与服务选项契约 | 修改服务输出字段 |

## 需要保留的行为

- 事件中的有效指标优先，摘要补齐空值或零值；旧产物没有事件时，仍能依靠摘要展示指标。
- 当前运行中的某案例没有 token 指标时，按时间向前查找最近的有效结果。已有指标的当前案例不会被旧结果覆盖。
- 总缓存命中率使用全部案例的命中 / 未命中 token 计算，不直接平均案例百分比。
- transcript 存在时展示会话；缺失时回退到最近事件。事件接口和会话接口使用相同的案例目录边界校验。
- 数据集准备任务属于服务实例。同一实例对同一目录复用准备 Promise，保留既有的每次启动内尝试策略。
- `workspace.ts` 通过配置作用域调用底层 SWE 服务，使默认路径使用本次应用配置。仓库缓存与 worktree 的实现仍在 `../swe/workspace.ts`。

验证入口为 `tests/evaluation-dashboard.test.ts`，运行 `npm run test:dashboard`。真实数据集下载和仓库准备需要对应 YAML 配置；回归测试使用临时数据和本地服务替身。
